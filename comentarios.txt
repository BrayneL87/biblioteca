git reset se utiliza para borrar todos los cambios y regresa al 
primer comentario que se subio y queda el proyecto desde el inicio
y lo utlice para corregir daños del proyecto

git push origin main --force el git push origin main subel el
el proyecto y junto --force lo que hace es obligar a que se 
sobrescriba con lo que tienes en tu local, aunque eso borre o 
reemplace el historial que ya estaba en GitHub.
